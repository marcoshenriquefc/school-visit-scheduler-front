# Handle Frontend

Initial frontend setup for Handle using Nuxt 3, Vue 3, TypeScript, Tailwind CSS, Pinia, and Zod.

## Requirements

- Node.js 20+
- npm 10+

## Setup

1. Copy environment file:
   ```bash
   cp .env.example .env
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run development server:
   ```bash
   npm run dev
   ```

## Scripts

- `npm run dev`: start development server
- `npm run build`: build production bundle
- `npm run preview`: preview production build
