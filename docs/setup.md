# Setup

## Requirements
- Node.js 20+
- npm 10+

## Run locally
1. Copy env file:
   ```bash
   cp .env.example .env
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run development server:
   ```bash
   npm run dev
   ```
4. Optional production build:
   ```bash
   npm run build
   npm run preview
   ```
